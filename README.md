# Stray agents (demo material)

Three "agents" the way most agencies actually have them - each works alone, none knows the
others exist, none has an owner on paper. Used in session 2 of the Agent-Native Agency workshop
to show the bring-your-own path: `/agent-dev:agent-fleet-analysis` → `/agent-dev:agent-fleet-migrate`
→ create on Trinity → tag into the Keymaker agency → grant the edge.

| Folder | What it is | Paradigm |
|---|---|---|
| `meeting-notes-bot/` | a Claude Code agent that turns call transcripts into client notes | Claude Code (`CLAUDE.md` + `.claude/skills/`) |
| `invoice-reminder-n8n/` | an n8n workflow export that nags overdue invoices | n8n JSON |
| `lead-scorer/` | a Python loop that scores inbound leads with an LLM call | freeform-coded |

Sample material for a fictional agency. Apache 2.0.
